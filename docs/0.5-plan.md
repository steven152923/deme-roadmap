# Deme Roadmap 0.5 implementation plan

0.5 is the private-workspace release.

## Security
- First-run passcode setup before roadmap data is exposed.
- Salted scrypt verifier in the Electron main process; plaintext passcodes are never persisted.
- Security config lives in Electron userData so updates do not replace it.
- Roadmap load/save/export/import/reveal IPC requires an unlocked session.
- Manual lock button and Ctrl+L.
- Optional inactivity auto-lock.
- Change passcode from Settings.

## Style presets
- Candy Cloud: pastel pink/lilac/sky, clouds, soft cards.
- Night Bloom: deep plum/navy, glowing pastel surfaces.
- Paper Pop: warm paper, coral/mint/lilac stickers and taped-card styling.

## New workspaces
- Calendar: month agenda combining work targets, release dates and decision review dates.
- Notes: pinned/color-coded local notes for planning, copy, research and meeting scratchpads.
- Decisions: record what was decided, why, related release, status and revisit date.
- Launch Center: release readiness checklist plus generated/editable release notes grouped from completed work.
- Focus Sessions: small 25/50/custom work timer in the app chrome with completed-session history.

## UX pass
- Grouped navigation: Plan / Capture / Ship.
- Theme picker with live previews.
- Daily overview surfaces next release, due work and recent private workspace activity.
- Command palette gains new workspace navigation and lock action.
