# Deme release QA feature inventory (source audit, 2026-09-13)

Source of truth: current working tree, not README. No Deme source edits.

- App shell: Expo SDK 57, prebuilt iOS/Android, auth/onboarding entry, five tabs (Home, Explore, Feed, Chats, Premium Settings), maintenance and global-ban gates, OTA notice, warm/cold launch, push/deep-link navigation. `App.tsx`, `src/navigation/*`, `src/app/AppProviders.tsx`, `app.config.js`.
- Identity: email signup, 6-digit verification and resend, email/password login, Discord login/signup, reset-code password recovery, team verification; onboarding stages include identity, interests, push choice, premium choice and persistence. `src/screens/auth/*`, `server/src/routes/auth.js`, `src/services/onboardingService.ts`.
- Discovery/home/feed: announcement cards, community and people recommendations, active presence, recent/popular feeds, search across communities/people/posts/tags, filters, pagination, pull-to-refresh. `HomeScreen`, `ExploreHomeScreen`, `FeedScreen`, `server/src/routes/search.js`.
- Communities: template/blank creation; name availability, image/GIF, category, language, public/private, theme, pledge; guest preview/join or join request, invitation, leave, module navigation, dock, pinned and featured content, widgets, ranking/check-in, events, safety, automations, ownership transfer/deletion. `CreateCommunityScreen`, `CommunityScreen`, `ManageCommunityScreen`, `server/src/routes/communities.js`, related route modules.
- Permissions: fixed community Owner/Leader/Curator/Helper/Observer roles; 15 named capabilities; platform team/owner override only after joining a community; equal/higher-rank and self-target actions denied. Separate platform moderation owner/team/steward capabilities. `server/src/services/communityAccess.js`, `server/src/services/moderation/permissionService.js`.
- Content: text/image/link-preview posts, drafts scoped to community, edit/delete, mentions/tags, content warnings, optimistic likes/reactions, comments/replies, poll and quiz create/vote/submit/results, journal rich editor, wiki variants and approval, OC cards and relationships, announcements. `CreatePostScreen`, `PostCard`, `JournalComposerScreen`, `BlogEditorScreen`, `WikiModule`, `OCPostEditorScreen`, `server/src/routes/posts.js`.
- Social/profile: global and community mini-profiles, edits, media/music, themes/frames/badges, manual status/presence, community-specific follows, followers/following, profile comments, blocks and reports. `ProfileScreen`, `UserProfileScreen`, `CommunityMiniProfileScreen`, `EditProfileScreen`, profile routes.
- Messaging/calls: chat hub/global-community filters/pins/search; private 1:1/group and public/roleplay rooms; text, media, GIFs, stickers, voice, replies, reactions, edit/delete, pins, typing/read state, history pagination/read anchors, moderation; roleplay personas/characters/DnD; YouTube screening playback; LiveKit/private/group/stream voice calls and interruption/VoIP push. `PrivateChatScreen`, `PublicChatRoomScreen`, `ChatsViewerScreen`, `server/src/routes/conversations.js`, `calls.js`.
- Notifications: in-app list/read/delete, native push registration/permission, public-chat mute/preferences, deep-link entry and fallbacks. `NotificationsScreen`, push services, `appLinking.ts`, `notificationNavigation.ts`.
- Monetization: RevenueCat monthly/yearly purchase, cancellation/restore, entitlement refresh and fallback, premium cosmetic frames/bubbles/themes/status gating. EAS release profiles enable RevenueCat. `revenueCatService.ts`, `PremiumScreen`, `PremiumContext`, premium routes.
- Settings/privacy/support: language, app theme, reduced motion, Android Lite Mode, push, connected Steam/Last.fm, activity status, blocked users, legal pages, support tickets, ownership transfer/account deletion. `SettingsScreen`, related routes.
- Extra enabled/conditional surfaces: Media Lab and livestream flags default off but EAS release profiles enable them; livestream creation is web/team-gated, mobile viewing/chat remains. Sticker cutout creator; roadmap and feature-ideas board; community automation and moderation workspaces. `featureFlags.ts`, `eas.json`, `MediaLabScreen`, livestream screens, `StickerCreateScreen`, `RoadmapScreen`.
- Localisation: en/es/fr/de/pt only, lazy locale loading and AsyncStorage preference, English fallback, interpolation. `src/config/languages/index.tsx`.
- High-risk code: auth restoration and OTA race; community draft scope and module switch; optimistic reaction rollback; chat socket/polling reconciliation, read anchors and keyboard; upload timeout/retry; permissions enforced server-side; RevenueCat/client-server entitlement sync; native push/VoIP; hardcoded English in active CreateCommunity, Premium and OC editor screens; Expo SDK 57 upgrade in dirty working tree.
- Exclusions: mockup-only routes and developer diagnostics are not primary release features; Android screen-share creation is unsupported, so Media Lab tests are access/control based; no real paid purchase is automated or performed by Codex.
